# 🚀 Fred Joaquim — Portfólio

Portfólio profissional de **Fred Joaquim**, desenvolvedor Full Stack Java em formação, que também cria sites e landing pages para negócios e profissionais autônomos.

🔗 **Online:** https://fredjoaquim.github.io/Portifolio-web/

---

## 🎯 Objetivo

Apresentar meus projetos, minha stack e meus serviços de forma clara, rápida e profissional, tanto para recrutadores quanto para clientes que precisam de um site ou sistema web.

## 🛠 Tecnologias utilizadas

- HTML5 semântico
- CSS3 (variáveis, Grid, Flexbox, animações)
- JavaScript puro
- Google Fonts
- Intersection Observer API

## ✨ Funcionalidades

- Navegação suave entre seções
- Animações de entrada ao rolar a página
- Efeito de brilho que acompanha o cursor (desktop)
- Cards de projetos com microinterações
- Layout totalmente responsivo (mobile first nos ajustes)
- Respeita a preferência de "reduzir movimento" do sistema
- Meta tags para SEO e compartilhamento
